Research & Key Projects

MedRecon-ARU: MRI & CT Image Reconstruction

Deep Learning

Attention Residual U-Net Architecture

Developed an Attention Residual U-Net (ARU-Net) for reconstructing noisy MRI and CT images, achieving PSNR 27.07 / SSIM 0.75 for MRI and PSNR 29.63 / SSIM 0.81 for CT.

Code Repository

Breast Cancer Detection & Localization

Ultralytics YOLO & Grad-CAM

Computer-Aided Detection Pipeline

Developed a detection pipeline using Ultralytics YOLO on a medical dataset of 1,642 images, achieving Box mAP50 of 94.76%, Precision of 93.80%, and Recall of 91.53% on independent test splits. Implemented Grad-CAM attention heatmaps to visualize spatial regions of interest for clinical interpretability.

Code Repository

Chest X-Ray Multi-Disease Detection & Localization

DenseNet / ViT & Grad-CAM

Multi-Label Classification Pipeline

Developed a multi-label classification pipeline to detect thoracic pathologies (e.g., Pneumonia, Effusion, Nodules) from chest radiographs, achieving a mean AUC-ROC of 0.912 on benchmark datasets with integrated Grad-CAM visualization modules.
